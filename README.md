# Nihil Kumar — Portfolio

A responsive, static portfolio for PHP and Laravel software engineer Nihil Kumar. The page includes an illustrative visitor check-in flow and interactive browser-side examples of API validation, tenant scoping, and SQL aggregation.

## Publish with GitHub Pages

1. Create a public repository named `nihilkumar19.github.io` in the GitHub account `nihilkumar19`.
2. Add the files in this folder to the repository's `main` branch.
3. In the repository, open **Settings → Pages** and set the source to **GitHub Actions**.
4. The included workflow deploys the static site on each push to `main`. The site will be available at `https://nihilkumar19.github.io` after the first successful deployment.

No build step, secrets, API keys, or backend services are required. The demo values are illustrative and run in the visitor's browser. The public portfolio includes direct phone and email contact links, a downloadable résumé, and a verified HackerRank profile link. No client code, customer data, or private project credentials are included.

## Local preview

Open `index.html` in a browser, or serve this directory with any static file server. Google Fonts are optional; system fallback fonts are provided.
